# Padel Lunch Challenge 2026

Sito statico ufficiale del Padel Lunch Challenge 2026 - Sport Up Padel Castegnato.

## Pubblicazione con GitHub Pages
1. Crea un repository pubblico chiamato `padel-lunch-challenge-2026`
2. Carica `index.html` e la cartella `assets`
3. Vai in Settings > Pages
4. Source: Deploy from a branch
5. Branch: main / root
6. Salva

Il sito sarà disponibile a:
`https://TUO-USERNAME.github.io/padel-lunch-challenge-2026/`
